# Limbo Keys

Чистый ремейк финальной секции с ключами из Geometry Dash — уровня **LIMBO**
(референс: `etherealxx/limbo-godot`). Без игровых движков: только C++
(Win32/GDI). Python нужен лишь для сборки и генерации ассетов-заглушек.

## Как играется

- 8 ключей в сетке 2×4, до перемешивания все оранжевые, верный мигает зелёным.
- Под музыку: на 5-й секунде начинается перемешивание и длится ровно 10 секунд
  (26 ходов). На 6-м и 13-м ходах верхний и нижний блоки ключей меняются
  местами, разворачиваясь на 180° по дугам.
- После перемешивания ключи собираются в круг и плавно едут по нему.
- Кликни по верному ключу → вспышка цветом → катсцена «компьютер спокойно
  проезжает по шипам» → диспетчер задач возвращается → игра закрывается.
- Ошибёшься → компьютер падает на шипы и взрывается голубым кольцом в стиле
  Geometry Dash → фейковый BSOD → после перезагрузки вас ждёт сюрприз от
  `trap.exe`, а избавитесь от него только с помощью `computer_repair.exe`.

> Инструкция по лечению компьютера: [REPAIR_YOUR_PC.md](REPAIR_YOUR_PC.md)

## Файлы

| Файл | Что делает |
|---|---|
| `dist/limbo key.exe` | сама миниигра |
| `build/trap.exe` | Узнаете ;) |
| `build/computer_repair.exe` | лечение ПК (см. [REPAIR_YOUR_PC.md](REPAIR_YOUR_PC.md)) |
| `installer.py` / `installer.exe` | сборка всего проекта в `dist/` |

## Настройка без пересборки

Рядом с игрой можно положить `settings.ini`:

```ini
[game]
shuffle_speed = 1.5
```

Множитель скорости перемешивания: от 0.25 до 4.0. При 1.0 (по умолчанию)
перемешивание синхронно треку — ровно 10 секунд.

## Сборка

Требуется MinGW-w64 (`g++`, `windres`, например MSYS2 UCRT64) и Python 3.8+.

```sh
python installer.py      # или rebuild.bat
```

Порядок: ассеты-заглушки → repair → trap → game (в игру вшиваются иконка и
trap/repair как ресурсы) → installer.exe → пакет `dist/`.

Иконки генерируются автоматически, если их нет: `key.ico` (игра), `trap.ico`
(тёмная рожица), `repair.ico` (монитор с зелёным крестом).

Все цвета, тайминги и тексты — в `src/common/config.h`.
