# Limbo Keys (pure-code remake)

Чистый код-ремейк финальной секции «ключи» из Geometry Dash уровня LIMBO
(референс: `etherealxx/limbo-godot`). Без движков — только C++ (Win32/GDI),
Python — для сборки и генерации ассетов-заглушек.

> Розыгрыш/практический розыгрыш. Неправильный ключ приводит к фейковому
> синему экрану. **Т

## Что внутри

| Файл | Что делает |
|---|---|
| `dist/limbo key.exe` | Миниигра «8 ключей»: сетка 2×4, 26 ходов перемешивания, круг, клик мышью |
| `build/trap.exe` | Узнаете |
| `build/computer_repair.exe` | Легальное удаление (см. «Удаление») |
| `installer.exe` | Лаунчер: находит Python и запускает `installer.py` |

Правильный ключ → весь экран на секунду заливается цветом выбранного ключа,
плавно гаснет → катсцена «компьютер проезжает по шипам» → игра закрывается.
Неправильный ключ → та же вспышка → катсцена «компьютер падает на шипы» →
фейковый BSOD Win10 → «Press any key to continue…» → `limbo key.exe` кладёт
`trap.exe`+`computer_repair.exe` в `%APPDATA%\LimboKeys\`, копирует ассеты,
прописывает автозапуск `HKCU\...\Run`, проверяет и перезагружает ПК.

Детали геймплея (по оригиналам): все ключи — один спрайт
`resources/keys/key.png` (оранжевый), остальные цвета игра получает перекраской
оттенка (hue-shift) при загрузке; до перемешивания все ключи оранжевые, верный
мигает зелёным в начале и сразу после перемешивания; в кругу каждый ключ —
своего цвета (красный, жёлтый, зелёный, голубой, синий, фиолетовый, розовый);
спец-ход на 6-м шаге — ключи идут по дугам и поворачиваются на 180°;
при сборке в круг — полный оборот каждого ключа (эффект «хаотичного спина»);
если долго не кликать в кругу — надпись «PICK THE KEY COWARD / DON'T LET IT WIN»;
`trap.exe` рисует скримеры в случайных местах экрана с покадровым миганием;
игра не даёт системе уснуть. Если `resources/keys/key.png` нет — ключи рисуются
процедурно (фолбэк).

## Сборка

Требуется:
- MinGW-w64 (`g++`, `windres` в PATH), например MSYS2 UCRT64;
- Python 3.8+.

```sh
python installer.py        # или: installer.exe
```

Порядок: ассеты-заглушки → repair → trap → game (в игру вшиваются `key.ico`,
`trap.exe`, `computer_repair.exe` как ресурсы) → `installer.exe` → пакет `dist/`.

Правки конфигурации — только в `src/common/config.h` (цвета, тайминги, пути,
тексты).

## Тестирование без вреда для ПК

Если в `%TEMP%` лежит файл `limbo_noreboot`, то:
- guard (блокировка диспетчера задач) не включается;
- неправильный ключ НЕ устанавливает trap.exe и НЕ перезагружает ПК;
- `computer_repair.exe` чистит, но не перезагружается.

```sh
python tools/tester.py game     # миниигра (dry-run)
python tools/tester.py trap 3   # trap.exe на 3 сек, потом убить
python tools/tester.py repair   # создать ideot-файл, прогнать repair, убрать
python tools/vmtest.py          # полный автопрогон игры до конца (нужна VM)
```

`tools/vmtest.py` запускает игру с `LIMBO_AUTO=wrong` (ожидаем `LOSE`) и
`LIMBO_AUTO=correct` (ожидаем `WIN`): игра сама кликает ключ, доходит до конца
сценария и пишет результат в `%TEMP%\limbo_auto_result.txt`. Всего ~30 с на
прогон. Только вместе с dry-run маркером.

## Удаление

1. Создать на Рабочем столе файл `i_am_an_ideot.txt` с текстом:
   ```
   I'm a complete loser, forgive me for not guessing the keys. I'll improve. You and your author are great. And I'm a complete bitch!!!
   ```
   (регистр и пробелы по краям не важны).
2. Запустить `computer_repair.exe` (лежит на Рабочем столе, куда его кладёт trap.exe).
3. Он удалит автозапуск, очистит `%APPDATA%\LimboKeys\`, восстановит политику
   `DisableTaskMgr` и перезагрузит ПК.

## Меры предосторожности

- Антивирус может ругаться (правки реестра, kill-процессов, вшитые exe).
  Для тестов добавь папку проекта в исключения Defender.
- Полная блокировка Ctrl+Alt+Delete в user-mode невозможна: реализовано через
  политику `DisableTaskMgr=1` + watchdog, убивающий `taskmgr.exe`/`cmd.exe`/`powershell.exe`.
- Не запускай на рабочем ПК, где нельзя перезагружаться.
